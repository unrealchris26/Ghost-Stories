# Ghost Stories: Is Seeing Really Believing?

Show website for Kent Axell's **Ghost Stories** at 1923 Prohibition Bar, inside Mandalay Bay, Las Vegas.
Static HTML, CSS and vanilla JS, deployed on Netlify, with one Netlify Function that sends form leads to GoHighLevel.

```
index.html          Home page (all 16 sections)
privacy.html        Privacy Policy     ┐ generated from index.html's header/footer
terms.html          Terms & Conditions │ by _source/build_pages.py
404.html            Not-found page     ┘
assets/css/styles.css
assets/js/main.js
assets/img/         Optimized WebP images + generated textures
assets/fonts/       Enigma + self-hosted Google Fonts (latin subsets)
assets/video/       Trailer / clip files
netlify/functions/lead.mjs
netlify.toml
_source/            Original photos, reference screenshot, rebuild scripts (never served)
```

## Run it locally

Any static server works:

```bash
npx serve .            # or: python -m http.server 8000
```

The forms need the Netlify function, so to test them locally use the Netlify CLI:

```bash
npm i -g netlify-cli
netlify dev            # reads GHL_TOKEN / GHL_LOCATION_ID from your Netlify site or a local .env
```

## Deploy (Netlify from GitHub)

1. Push this folder to a GitHub repo.
2. In Netlify: **Add new site → Import from Git**, pick the repo. No build command is needed; `netlify.toml` sets the publish directory (`.`) and functions directory.
3. Add the environment variables below, then trigger a deploy.

## GoHighLevel environment variables

Set these in **Netlify → Site configuration → Environment variables**:

| Variable | Value |
| --- | --- |
| `GHL_TOKEN` | A Private Integration token (Settings → Private Integrations) with the `contacts.write` scope |
| `GHL_LOCATION_ID` | The sub-account's Location ID (Settings → Business Profile) |

In GHL, create these contact custom fields with exactly these keys (Settings → Custom Fields):
`event_date`, `event_type`, `event_details`.

What the function sends (`POST /.netlify/functions/lead` → `contacts/upsert`):

- `source: "ghost-stories-site"`
- Booking form: name, email, phone, the three custom fields, tags `ghost-stories`, `booking-inquiry`, `event: <type>`
- Newsletter form: email, tags `ghost-stories`, `newsletter`
- A hidden honeypot field (`company`) silently drops bot submissions.

If a submission fails, check **Netlify → Logs → Functions → lead**. The function logs GHL's response body.

## Swapping images

Every placeholder has a `<!-- TODO -->` comment next to it in `index.html`. Two ways to swap:

- **Easiest:** save your new photo over the existing file in `assets/img/` with the same filename (WebP preferred, JPG works if you also change the extension in the HTML).
- **Rebuild from originals:** drop photos into `_source/photos/`, edit the filename map in `_source/build_assets.py`, then run `python _source/build_assets.py` (needs Pillow). It resizes, crops and converts to WebP.

Notes:

- **Hero:** a single photo, `hero-ghost-stories-bg.webp` (1920 wide) plus `hero-ghost-stories-bg-1280.webp` for smaller screens. The text group is vertically centred, but never rises above `--face-clear` in `styles.css` (35% of the screen height, 36% on phones), which sits just below Kent's chin in this photo. If you swap in a photo where the face sits higher or lower, adjust `--face-clear` to match. Rebuild both sizes from `_source/photos/Ghost Stories Web Background 3.webp` with the build script, and update the `<link rel="preload">` in `<head>` if you rename them.
- **Tape marquee (first band):** the aged gold tape is `assets/img/marquee-tape.webp`, generated by `python _source/build_tape.py` (change the colours, stains or torn edges there).
- **Gallery:** eight square photos (`gallery-gs-NN-640.webp` in the grid, `gallery-gs-NN.webp` full size in the lightbox). They are never cropped. To add or swap one, drop a square `GS Snapshot N.jpg` into `_source/photos/gallery/`, run `python _source/build_assets.py`, and copy an existing `<li class="plate">` in `index.html`: point the `<img src>` and `--src` at the 640 preview and `data-full` at the full-size file. Give each a short `alt`; it is read by screen readers only, nothing is shown on the page.
- **Meet Your Medium:** a transparent cut-out portrait looks best (it glows against the candle halo).
- **Venue strip logos:** Mandalay Bay, Unreal Productions and the Google rating are typeset placeholders. Replace each `<span class="mark">` with an `<img>` of the real logo; the sepia filter is applied automatically.
- **Logo:** the nav and footer use a text logo, not an image: "GHOST STORIES" in Enigma with "Is Seeing Really Believing?" in Special Elite beneath it (the letters L-I-E in white). The same lockup is used for the hero title and subtitle.

## Video

The trailer button and the three clip cards open a video dialog. Each has a `data-video-src` attribute. Point it at an `.mp4`/`.webm` in `assets/video/`. Every clip currently uses the same placeholder loop.

Prefer YouTube? Replace the `<video>` inside `<dialog class="video-dialog">` with an `<iframe>` and set its `src` in `assets/js/main.js` (the `[data-video-open]` click handler).

## Fonts

- **Enigma** (show title and logo only) lives at `assets/fonts/enigma.woff2` and is loaded in the `@font-face` block at the top of `styles.css`. If you get additional formats (`.woff`, `.ttf`), add them to that block's `src` list. If the file is ever missing, the title falls back to Limelight.
- Josefin Sans (headlines, navigation, buttons, labels), Cormorant Garamond (body) and Special Elite (typewriter accents) are self-hosted latin subsets; no Google Fonts request at runtime.

## Title lockup (hero and logos)

The subtitle "IS SEEING REALLY BELIEVING?" is fitted by `assets/js/main.js` (`fitAll`) so its left and right edges line up exactly with "GHOST STORIES" above it, in the hero, the nav logo and the footer logo. It widens the subtitle with letter-spacing (the type keeps its height), then applies a tiny `scaleX` for the last few pixels. On phones, where the title stacks onto two lines, the subtitle matches the wider line and its type is sized down slightly instead of being squashed. It re-fits when fonts load and whenever the title changes size, so it stays aligned at every screen width.

To use the lockup elsewhere, give the wrapper `data-lockup`, the title `data-lockup-title`, and the subtitle `data-lockup-sub` with its text inside `<span class="lockup-fit">`. Without JavaScript the subtitle simply sits centred under the title.

## Updating copy

All copy is plain HTML in `index.html`, section by section (each section starts with a numbered comment like `<!-- 8. Choose your encounter -->`).

Things to check before launch (marked `TODO` in the HTML):

- **Tickets link:** set `TICKETS_URL` at the top of `assets/js/main.js`. Until then, every "Get Tickets" / "Reserve Your Seat" button scrolls to the enquiry form.
- **FAQ facts:** run time (currently "about 75 minutes"), dress code and password details.
- **Venue address**, **Instagram/YouTube URLs**, **Google reviews link**.
- **Domain:** once live, uncomment the canonical tag and make `og:image` an absolute URL in `<head>`.
- Have the Privacy Policy and Terms reviewed.

If you edit the nav or footer in `index.html`, run `python _source/build_pages.py` to copy the change to the Privacy, Terms and 404 pages.

## Easter eggs

- **The planchette** in the footer: rest the cursor on it (or focus it with the keyboard, or press and hold on a phone) for three seconds to reveal the speakeasy password. Change it via `SPEAKEASY_PASSWORD` in `main.js`.
- **The console** asks "Are you still there?" after about seven seconds.
- **The gallery:** hover the photo of the hanging bell long enough and a figure appears in the double exposure.

## Motion and accessibility

- All ambient motion (grain, fog, gaslight flicker, candle glow, marquees, word materialize, séance spelling) stops under `prefers-reduced-motion: reduce`; content appears in its final state.
- The hero subtitle hides "LIE" in white inside "BeLIEving", and screen readers hear the plain sentence "Is Seeing Really Believing?".
- Grain and vignette are fixed, pointer-events-free layers; the fog texture loads after the page `load` event so it never competes with the hero image.
